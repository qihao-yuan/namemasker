# NameMasker - 隐私遮盖工具

自动识别并遮盖图片、Word 文档、PDF 中的人名、手机号、身份证号等敏感信息。支持大模型 API 自动识别 + 手动画框，批量处理整个文件夹。

## ✨ 功能

- **大模型自动识别** - 调用 Qwen-VL / GPT-4o 等视觉大模型，自动定位图中敏感文字
- **手动画框** - 在图片上直接拖拽画框，精确标记需要遮盖的区域
- **多种遮盖方式** - 填充、模糊、像素化、棋盘格（半透明灰白格）
- **批量处理** - 选择文件夹一键处理，支持子文件夹递归扫描
- **多轮查漏** - 自动遮盖已识别区域后再次检查，减少遗漏
- **边缘识别** - 对图片四周边缘区域单独识别，防止边角遗漏
- **自定义识别目标** - 不限于人名，可自定义为手机号、地址、身份证号等任意内容
- **API 可配置** - 支持 DashScope、OpenAI 等任意 OpenAI 兼容接口
- **设置自动保存** - API Key、模型名等设置关闭时自动保存，下次无需重填
- **预览功能** - 保存前预览遮盖效果
- **拖拽打开** - 直接拖拽图片/文档到窗口打开（需安装 tkinterdnd2）
- **Word 文档处理** - 自动识别并替换 docx 中的敏感文本，遮盖文档内嵌图片
- **PDF 文档处理** - 文字型 PDF 精确 redaction，扫描型 PDF 渲染后图像遮盖

## 📦 安装

### 方式一：pip 安装

```bash
pip install namemasker
```

### 方式二：源码安装

```bash
git clone https://github.com/qihao-yuan/namemasker.git
cd namemasker
pip install -e .
```

### 方式三：直接下载 exe

前往 [Releases](https://github.com/qihao-yuan/namemasker/releases) 下载最新版 `NameMasker.exe`，双击即用。

## 🚀 使用

### 启动

```bash
# pip 安装后
namemasker

# 或源码运行
python -m namemasker
```

### 快速上手

1. 填写 API Key（支持 DashScope / OpenAI 等）
2. 打开图片（按钮 / Ctrl+O / 拖拽）
3. 点击「自动识别」或手动画框标记区域
4. 选择遮盖方式，点击「预览」查看效果
5. 点击「保存」(Ctrl+S) 导出

### 批量处理

1. 填写 API Key 和模型设置
2. 点击「批量处理文件夹」
3. 选择输入文件夹和输出文件夹
4. 等待处理完成，可随时取消

### 文档处理 (Word / PDF)

1. 填写 API Key
2. 点击「处理文档」或拖拽 .docx / .pdf 文件到窗口
3. 选择保存路径
4. Word: 敏感文本替换为 `***`，内嵌图片自动遮盖
5. PDF: 文字型页面精确遮盖，扫描页渲染为图像后遮盖

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开图片 |
| Ctrl+S | 保存 |
| Ctrl+Z | 撤销上一个框 |
| 右键点击框 | 删除该框 |

## ⚙️ 配置

### API 设置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| API Key | 大模型服务的密钥 | 环境变量 `DASHSCOPE_API_KEY` |
| API 地址 | OpenAI 兼容接口地址 | DashScope |
| 模型 | 视觉语言模型名称 | qwen2.5-vl-72b-instruct |
| 识别轮数 | 多轮查漏检查次数 | 2 |
| 识别目标 | 要识别的内容描述 | 中文人名 |

### 遮盖设置

| 参数 | 说明 |
|------|------|
| 遮盖方式 | 填充 / 模糊 / 像素化 / 棋盘格 |
| 边距扩展% | 向外扩展遮盖区域的比例 |

## 📋 依赖

- Python >= 3.9
- Pillow >= 10.0.0
- openai >= 1.0.0
- tkinterdnd2 >= 0.3（可选，拖拽功能）
- python-docx >= 1.0.0（可选，Word 文档处理）
- PyMuPDF >= 1.24.0（可选，PDF 文档处理）
